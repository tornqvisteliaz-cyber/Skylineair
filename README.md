# Skyline ACARS PRD

Detta projekt innehåller en Next.js-baserad produktsida som visualiserar produktkravsdokumentet för **Skyline ACARS** — ett pilot- och virtual airline-datalänkssystem för **Microsoft Flight Simulator 2024**.

## Innehåll

Sidan sammanfattar följande delar av PRD:n:

- Produktöversikt och målbild
- Funktionskrav för flight data capture
- ACARS-meddelanden mellan pilot och dispatch
- Backend-integration, säkerhet och robusthet
- Teknisk stack
- Användarflöde
- MVP, stretch goals och leverabler

## Kom igång

Installera beroenden och starta utvecklingsservern:

```bash
npm install
npm run dev
```

Öppna sedan [http://localhost:3000](http://localhost:3000).

## Skript

- `npm run dev` – startar utvecklingsservern
- `npm run build` – bygger produktionsversionen
- `npm run start` – kör den byggda applikationen
- `npm run lint` – kör ESLint
